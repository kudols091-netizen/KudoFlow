Bắt đầu

Chào mừng đến với KudoSkill

KudoSkill là Chrome Extension giúp bạn tự động hóa các tác vụ AI — kéo thả node, kết nối ChatGPT · Grok · Gemini · Google Flow trong một workflow, chạy hàng loạt mà không cần code.

Workflow Builder

Kéo thả node, kết nối AI bằng mũi tên. Không cần code.

Batch Generate

Submit hàng chục prompt cùng lúc, auto-retry khi lỗi.

Multi-task Queue

Chạy song song nhiều job, tránh quota throttling.

Auto Download

Tự động lưu ảnh với tên file template (date, prompt, index).

Telegram Bot

Nhận kết quả AI trực tiếp qua Telegram.

AI Agent (MCP)

Ra lệnh bằng ngôn ngữ tự nhiên cho Claude điều khiển workflow.

💡 Mẹo: Bạn không cần API key riêng — KudoSkill dùng phiên đăng nhập ChatGPT, Grok, Gemini đang mở trên trình duyệt.
Cài đặt

Cài đặt Extension

Cài KudoSkill từ Chrome Web Store trong vòng 30 giây — không cần cấu hình thêm gì.

1

Mở Chrome Web Store

Truy cập Chrome Web Store, tìm kiếm KudoSkill hoặc click link cài đặt trực tiếp trên trang chủ.

2

Bấm "Thêm vào Chrome"

Xác nhận cài đặt trong hộp thoại hiện ra. Extension sẽ tự tải về và cài trong vài giây.

3

Đăng ký tài khoản

Click vào icon KudoSkill trên thanh toolbar → Đăng ký. Dùng thử miễn phí 7 ngày, không cần thẻ tín dụng.

4

Mở tab AI và bắt đầu

Mở tab ChatGPT, Grok, hoặc Gemini. Click icon KudoSkill → sidebar xuất hiện bên phải. Bạn đã sẵn sàng!

ℹ️ Cốc Cốc & Edge: KudoSkill hoạt động trên mọi trình duyệt nền Chromium — Cốc Cốc, Edge, Brave — cài bình thường từ Chrome Web Store.
Tính năng

Workflow Builder

Xây dựng chuỗi tác vụ AI bằng giao diện kéo thả. Kết nối các node với nhau — kết quả của node trước tự động truyền vào node sau.

KudoSkill — Workflow Builder Demo
Video hướng dẫn Workflow Builder Coming soon
1

Tạo Workflow mới

Vào sidebar KudoSkill → tab Workflow → bấm + Tạo mới hoặc chọn template có sẵn.

2

Thêm Node AI

Kéo node từ panel trái vào canvas. Mỗi node đại diện cho một bước — ChatGPT, Grok, Gemini, hoặc Google Flow.

3

Kết nối các Node

Kéo mũi tên từ output của node này sang input của node khác. Kết quả sẽ tự động truyền qua.

4

Nhập Prompt & Run

Click vào node, nhập prompt. Bấm ▶ Run — toàn bộ chuỗi tự chạy, kết quả hiển thị real-time.

💡 Dùng biến: Nhập {"{"}{"{"}input{"}"}{"}"} trong prompt để nhận giá trị từ node trước. Ví dụ: "Dịch đoạn văn sau sang tiếng Anh: {"{"}{"{"} input {"}"}{"}"}"
Tính năng

Batch Generate

Submit hàng chục prompt trong một lần click. KudoSkill tự xử lý lần lượt, auto-retry khi gặp lỗi, tải ảnh/text về với tên file template.

Multi-prompt

Nhập danh sách prompt, chạy toàn bộ không cần giám sát.

Auto-retry

Tự thử lại khi AI bị lỗi hoặc quota hết — không bỏ sót prompt nào.

Tên file template

Đặt tên file theo date, prompt, index tự động.

Queue thông minh

Kiểm soát tốc độ để tránh bị giới hạn rate của từng nền tảng AI.

⚠️ Lưu ý: Mỗi nền tảng AI có giới hạn request khác nhau. KudoSkill tự điều chỉnh tốc độ nhưng bạn nên giữ số lượng batch dưới 50 prompt/lần để tránh bị tạm khóa.
Tính năng

Multi-task Queue

Chạy nhiều workflow song song trên cùng lúc. KudoSkill quản lý hàng đợi thông minh — tối ưu throughput mà không vi phạm quota.

1

Thêm nhiều task vào Queue

Từ Workflow Builder, bấm Add to Queue cho từng workflow muốn chạy song song.

2

Cấu hình concurrency

Chọn số job chạy đồng thời (mặc định 3). Cao hơn = nhanh hơn nhưng dễ bị throttle.

3

Chạy Queue

Bấm ▶ Run Queue — các job tự phân phối, bạn có thể đóng tab và quay lại sau.

Tính năng

Auto Download

Ảnh và kết quả AI tự động lưu về máy với tên file được đặt theo template — không cần tay tải từng file.

Template tên file

Dùng biến {date}, {index}, {prompt} để đặt tên tự động.

Cấu trúc thư mục

Tự tạo subfolder theo ngày hoặc tên project.

Ảnh chất lượng cao

Tải ảnh gốc 2K/4K từ Google Flow, không bị nén.

Bulk export

Tải toàn bộ kết quả trong một batch thành file ZIP.

💡 Ví dụ template: {"{"} date {"}"}_{"{"} index {"}"}_product-shot → tạo ra 20260630_001_product-shot.png
Tính năng

Đa nền tảng AI

KudoSkill hỗ trợ 4 nền tảng AI hàng đầu trong cùng một workflow. Chuyển nền tảng tức thì — không cần học lại cách dùng từng tool.

ChatGPT

Viết nội dung, phân tích, tóm tắt, dịch thuật. Hỗ trợ GPT-4o.

Grok

Real-time data, phân tích thị trường, nội dung sáng tạo.

Gemini

Đa phương tiện, xử lý ảnh, tạo caption, phân tích hình ảnh.

Google Flow

Sinh ảnh AI chất lượng cao, Imagen 3, xuất 4K.

Tính năng

Telegram Bot

Kết nối KudoSkill với Telegram — nhận thông báo khi workflow hoàn thành, hoặc gửi lệnh chạy workflow trực tiếp từ điện thoại.

1

Tạo Bot Telegram

Tìm @BotFather trên Telegram → /newbot → đặt tên → nhận Bot Token.

2

Kết nối với KudoSkill

Vào KudoSkill → Cài đặt → Telegram → nhập Bot Token → bấm Kết nối.

3

Xác thực Chat ID

Gửi tin nhắn đến bot vừa tạo → bấm Xác thực trong KudoSkill để liên kết tài khoản.

4

Nhận thông báo

Từ giờ mỗi khi workflow hoàn thành, kết quả sẽ được gửi về Telegram của bạn tự động.

ℹ️ Bot cá nhân: Bạn có thể dùng bot riêng (gói Team) để ẩn branding KudoSkill — khách hàng chỉ thấy tên bot của bạn.

Điều khiển bằng chat

"Tạo workflow gen ảnh sản phẩm và chạy với 10 prompt này"

Tự động hóa sâu

Read & Write

Agent đọc kết quả, phân tích, và tiếp tục chạy bước tiếp theo.

FAQ

Câu hỏi thường gặp

Những thắc mắc phổ biến nhất từ người dùng KudoSkill.

KudoSkill có cần API key không?

Không. KudoSkill dùng phiên đăng nhập sẵn có của bạn trên các tab ChatGPT, Grok, Gemini đang mở. Bạn không cần mua thêm API key hay trả tiền cho từng nền tảng.

Dữ liệu workflow có bị mất khi hết trial không?

Không. Tất cả workflow được lưu trên tài khoản. Khi hết trial bạn không thể chạy thêm workflow mới nhưng dữ liệu vẫn được giữ nguyên đến khi nâng cấp.

Extension có hoạt động trên Cốc Cốc không?

Có. Cốc Cốc dùng nền Chromium tương tự Chrome, bạn cài extension từ Chrome Web Store bình thường.

Thanh toán như thế nào?

Chuyển khoản ngân hàng nội địa (TPBank). Hệ thống tự xác nhận qua SePay trong vòng 1-2 phút sau khi nhận tiền. Không cần thẻ quốc tế.

Tôi có thể hủy gói bất cứ lúc nào không?

Có. Gói tháng không tự gia hạn — bạn chủ động gia hạn khi muốn. Gói năm áp dụng chính sách hoàn tiền trong 7 ngày nếu không hài lòng.
